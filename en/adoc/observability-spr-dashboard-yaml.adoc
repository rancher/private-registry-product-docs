[#pr-observability-spr-dashboard-yaml]
== SPR Dashboard YAML definition

The following YAML definition creates a dashboard in {sobservability} for monitoring {harbor} metrics.
This dashboard displays eight key metrics for the registry health and operations.

[source,yaml]
----
metadata:
  project: '{"saveVariables":false}'
spec:
  panels:
    QdMW0bIQL2P6RaQMSVcFG:
      spec:
        plugin:
          kind: StatChart
          spec:
            calculation: last
            format: {}
            sparkline: false
            thresholds:
              defaultColor: "#33A02C"
              steps: []
        links: []
        queries:
          - kind: TimeSeriesQuery
            spec:
              plugin:
                kind: PrometheusTimeSeriesQuery
                spec:
                  query: min(harbor_health{namespace="suse-registry"})
        display:
          name: Registry Health
          description: "1 = healthy; 0 = unhealthy. Missing data is not healthy."
    qJzTSNXd5mgiFP59Wz0-r:
      spec:
        plugin:
          kind: StatChart
          spec:
            calculation: last

              steps: []
        links: []
        queries:
          - kind: TimeSeriesQuery
            spec:

                kind: PrometheusTimeSeriesQuery

                  query: sum(harbor_project_total{namespace="suse-registry"})
        display:
